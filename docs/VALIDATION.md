## 可复现入口

```sh
python scripts/verify_software.py --output docs/software-validation.json
python scripts/verify_assistive.py
python scripts/count_code.py
python -m robot_voice_patrol.hardware_gateway
```

浏览器测试需要安装 Playwright 和浏览器并显式启动 mock 服务：生活套件使用 `--home --fixture-skills`，传统套件使用默认配置与 `--fixture-skills`。设置 `UI_URL` 后运行 `tests/ui_*.cjs`；测试会创建自己的软件记录。机器可读报告：software-validation.json、ASSISTIVE_COVERAGE.json、BROWSER_VALIDATION.json、ROS_INTERFACE_VALIDATION.json、PACKAGE_VALIDATION.json、ARCHIVE_VALIDATION.json。

代码量采用物理行数，包括注释与空行；生产代码、测试/评估代码、ROS 接口/启动/构建脚本分开统计，依赖、文档、模型、数据和构建缓存不计入。见 [CODE_STATISTICS.json](CODE_STATISTICS.json)。
